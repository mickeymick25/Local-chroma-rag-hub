# Conventions

## conventions::001
<!-- created: 2026-09-04 -->
Les documents Git sont la source de vérité ; Chroma est un index dérivé,
reconstruisible à tout moment.

## conventions::002
<!-- created: 2026-09-04 -->

sous-collections.
